# Blackened Tree & Property Services

A mobile-first demo site for Austin Blackner's local tree and property service business in the Johnstown / Cambria County area.

## Run it

No build step or dependencies are required.

```bash
git clone https://github.com/buchk/Austinsite.git
cd Austinsite
python -m http.server 8000
```

Then open http://localhost:8000.

## Customize

- Contact details: edit `site.js`.
- Before/after project photos: add images under `assets/` and replace the demo panels in `index.html`.
- Service copy and service area: edit `index.html`.
- Branding and layout: edit `styles.css`.
